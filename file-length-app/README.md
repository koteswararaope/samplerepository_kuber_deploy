# File Length Checker Web Application

A simple, elegant web application that allows users to select a file and view its length/size along with other file information.

## Features

- 📁 File selection with drag-and-drop style interface
- 📊 Displays file size in bytes and human-readable format (KB, MB, GB, etc.)
- � Shows additional file information (name, type, last modified date)
- 🎨 Modern, responsive design with smooth animations
- 💻 Works entirely in the browser (no server required)

## How to Use

1. Open `index.html` in any modern web browser
2. Click on the "Choose a file" area or the upload icon
3. Select any file from your computer
4. View the file information displayed on the same page

## File Information Displayed

- **File Name**: The name of the selected file
- **File Type**: The MIME type of the file
- **File Size (Bytes)**: Exact size in bytes
- **File Size (Readable)**: Human-readable format (KB, MB, GB, etc.)
- **Last Modified**: Date and time when the file was last modified

## Technologies Used

- HTML5
- CSS3 (with animations and gradients)
- Vanilla JavaScript (ES6+)

## Browser Compatibility

Works on all modern browsers:
- Chrome
- Firefox
- Safari
- Edge

## Privacy

All file processing happens locally in your browser. No files are uploaded to any server.
